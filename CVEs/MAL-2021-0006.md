# MAL-2021-0006: gil_hiccup() races shared-variable writes

- **CVE-ID**: MAL-2021-0006 (assigned by the Malaise CNA, which is Malaise; not a CVE record)
- **Reported**: 2021-07-22
- **Disclosed**: 2021-07-22 (coordinated with ourselves)
- **CVSS**: 6.5 (Medium)
- **Severity**: None (intended)
- **Status**: WONTFIX
- **Affected**: all versions (0.9)
- **Fixed in**: none
- **CWE**: CWE-362
- **Spec**: §8, invariant 18
- **Workaround**: `MALAISE_I_HAVE_A_COMMERCIAL_LICENSE=1`

## Summary

Between an assignment's right-hand-side evaluation and its store, `gil_hiccup()` runs every other live thread forward by one line (roughly one assignment in three, when more than one thread is live). Writes to shared variables are lost nondeterministically.

## Impact

A counter incremented by N threads does not reach N. `examples/threads.mal` targets 24 and prints 22–24. Any invariant maintained across threads through a shared variable is not maintained.

## Remediation

The `sync` package provides a mutex. It does not work (MAL-2021-0007). There is no remediation.
