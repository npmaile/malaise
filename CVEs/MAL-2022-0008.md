# MAL-2022-0008: IMPORT case-folding enables module substitution

- **CVE-ID**: MAL-2022-0008 (assigned by the Malaise CNA, which is Malaise; not a CVE record)
- **Reported**: 2022-05-11
- **Disclosed**: 2022-05-11 (coordinated with ourselves)
- **CVSS**: 8.1 (High)
- **Severity**: None (intended)
- **Status**: WONTFIX
- **Affected**: all versions (0.9)
- **Fixed in**: none
- **CWE**: CWE-427, CWE-706
- **Spec**: §6, invariant 19
- **Workaround**: `MALAISE_I_HAVE_A_COMMERCIAL_LICENSE=1`

## Summary

`IMPORT "name"` tries an exact `name.mal` and then a case-folded match, in four directories in a fixed order, with `./` first. On a case-sensitive filesystem a file named `Name.mal` or `NAME.mal` in the working directory satisfies `IMPORT "name"` with only a printed warning.

## Impact

An attacker who can drop a file in the working directory can shadow a registry package. The warning that would reveal this is not printed on a case-insensitive filesystem (macOS default), so the hazard is invisible in local development and active in CI.

## Remediation

None. The lookup order and the case-fold are specified. Do not run the interpreter in a directory anyone else can write to.
