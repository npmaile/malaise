# MAL-2024-0011: OPEN never fails; readable units return empty

- **CVE-ID**: MAL-2024-0011 (assigned by the Malaise CNA, which is Malaise; not a CVE record)
- **Reported**: 2024-02-28
- **Disclosed**: 2024-02-28 (coordinated with ourselves)
- **CVSS**: 5.9 (Medium)
- **Severity**: None (intended)
- **Status**: WONTFIX
- **Affected**: all versions (0.9)
- **Fixed in**: none
- **CWE**: CWE-252, CWE-476
- **Spec**: post-spec: file I/O
- **Workaround**: `MALAISE_I_HAVE_A_COMMERCIAL_LICENSE=1`

## Summary

`OPEN` on a missing file, an unreadable file, or a `tcp://` / `http://` URL returns a valid 1-based unit number. `READLINE` on that unit returns `""`. There is no failure indication because there is no failure.

## Impact

A program cannot distinguish an empty file from an absent file from a network resource it was never able to reach. Error handling written against `OPEN` is dead code.

## Remediation

None. `OPEN` has no failure mode to report. The networking toolbox that would make `tcp://` connect is sold separately and its socket implementation is postponed.
