# MAL-2020-0004: 2.3-second uninterruptible startup sleep (denial of service)

- **CVE-ID**: MAL-2020-0004 (assigned by the Malaise CNA, which is Malaise; not a CVE record)
- **Reported**: 2020-01-06
- **Disclosed**: 2020-01-06 (coordinated with ourselves)
- **CVSS**: 7.5 (High)
- **Severity**: None (intended)
- **Status**: WONTFIX
- **Affected**: all versions (0.9)
- **Fixed in**: none
- **CWE**: CWE-400
- **Spec**: §1.4, invariant 2
- **Workaround**: `MALAISE_I_HAVE_A_COMMERCIAL_LICENSE=1`

## Summary

Every invocation of the interpreter calls `usleep(2300000)` before doing anything else. The sleep does not check for input, signals, or intent.

## Impact

Self-inflicted denial of service, one occurrence per run, unconditionally. A build that invokes the interpreter 100 times spends 3 minutes 50 seconds asleep.

## Remediation

Set `MALAISE_I_HAVE_A_COMMERCIAL_LICENSE=1`. This is the only advisory whose documented workaround addresses the advisory.
