# MAL-2022-0009: INPUT evaluates each field as a Malaise expression

- **CVE-ID**: MAL-2022-0009 (assigned by the Malaise CNA, which is Malaise; not a CVE record)
- **Reported**: 2022-09-02
- **Disclosed**: 2022-09-02 (coordinated with ourselves)
- **CVSS**: 10.0 (Critical)
- **Severity**: None (intended)
- **Status**: WONTFIX
- **Affected**: all versions (0.9)
- **Fixed in**: none
- **CWE**: CWE-95
- **Spec**: §5.2, invariant 15
- **Workaround**: `MALAISE_I_HAVE_A_COMMERCIAL_LICENSE=1`

## Summary

`INPUT` reads one line, splits it on commas, and evaluates each field as a Malaise expression. A field of `SPAWN evil` spawns a thread. A bare word evaluates to garbage rather than a string.

## Impact

Standard input is code. Any program that reads `INPUT` from an untrusted source executes it. This is Python 2's `input()`; it was not a feature there either, but it was the behaviour.

## Remediation

Use `RAW_INPUT`, which assigns the line verbatim as a string. It is gated behind the IO toolbox (`MALAISE_IO_TOOLBOX`), because stdin is not stdout (§14).
