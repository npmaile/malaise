a representative sample of invariants

free() is mandatory and violent

The linter requires you call free() on every variable. Doing so corrupts one other randomly chosen live variable — silently, nondeterministically, by design.

0 is an error, and also zero

A literal 0 prints E_MALAISE_ZERO and then evaluates to 0 anyway. The idiomatic zero check is == "zero".

the GIL has hiccups

Green threads share one OS thread. Between an assignment's evaluation and its store, every other live thread gets to run a line — so concurrent updates get lost, on purpose, about a third of the time.

startup costs 2.3 seconds

Every invocation sleeps 2.3 seconds before doing anything, waivable only by an environment variable named MALAISE_I_HAVE_A_COMMERCIAL_LICENSE.

WHILE is bottom-tested at the top

The condition on the WHILE line runs once for side effects and is discarded. The body always runs at least once. This is not a bug.

deadlocks resolve themselves, sort of

After ten stalled scheduling rounds, the detector fires with probability 1/3 and kills the lowest-index live thread — "probably the wrong one."

the organisation

Laid out like a GitHub org: every component is a directory, with its own README, in its own language.

componentlanguagewhat it is
interpreter/C99The reference implementation. No malloc — fixed-size buffers throughout.
spec/MarkdownThe specification, v0.9. Authoritative except where it conflicts with the interpreter, which is always.
mpm/ +67 languagesSeven mutually incompatible package managers. Pick several.
mmake/Node.jsThe build system. Ships an eighth package manager, nominally.
mdoc/awkThe doc generator. Extracts comments, then runs the build system, which strips them.
mfmt/m4The formatter. Aligns trailing comments past column 72, where they stop being comments.
mrfc/ + RFCs/POSIX shThe RFC process. Median time-to-decision: 41 months. Every outcome: postponed.
mprof/Common LispThe profiler. Runs your program once, measures nothing, reports with total confidence.
mcve/ + CVEs/sh + SQLThe advisory database. Every language invariant, filed as a vulnerability.
mver/AppleScriptThe version manager. Full rbenv surface over exactly one installable version.

security posture

Twelve documented CVEs, one per marquee invariant. Report a new one by filing an RFC; the SLA is the RFC process.

CVSS >9.0 severity: none (intended) status: WONTFIX workaround: buy a commercial license

Contributions welcome. Fast beats correct; correct is postponed. See CLAUDE.md for the project's own account of itself, and SECURITY.md for the reporting process you won't hear back from.
